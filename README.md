## How to Run

To make sure the Dart code works, testers have installed Dart SDK in their <a href=https://dart.dev/get-dart>official website</a> to use the Dart compiler as well as installing prerequisite extensions within VSCode.

### Installation
1. Go to the official website: https://dart.dev/get-dart
2. Follow the steps provided by the websites.
3.  Install the Dart extenstion provided by VSCode
4. Run ``dart --version`` in the terminal to verify installation

### Prerequisites
There are several ways to run the program:
* Press `F5` to run the program.
* Press `Ctrl + F5` to run the program without debugging.
* Navigate to the terminal and type
``dart bin\dart_exercises.dart`` to compile and run the program inside the terminal.

Once done, the provided code will run. An example output will be shown below.
